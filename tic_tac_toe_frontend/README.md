# Tic Tac Toe Frontend

A lightweight React app to play classic Tic Tac Toe:
- 2 players on the same device
- Play versus a simple AI
- Displays current turn, status, and running scores
- Announces winner or tie
- New Game and Reset Score actions

## Run locally

- Install dependencies: `npm install`
- Start dev server: `npm start`
- Open http://localhost:3000

## Usage

- Choose mode: 2 Players or Vs AI
- Click any empty cell to place your mark (X starts every game)
- Vs AI: AI plays as O
- New Game: clears the board and starts a new round (scores persist)
- Reset Score: clears scores and starts a new round

## Design

- Light, minimalistic theme
- Colors:
  - Primary: #1976d2 (X)
  - Accent: #e53935 (O)
  - Secondary: #424242
- Responsive, centered board with controls below
